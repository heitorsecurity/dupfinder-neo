dupfinder-neo Development History

Scope

Este historico registra o ciclo de desenvolvimento, evolucao e modernizacao do projeto dupfinder-neo em c:\Users\hteix\code\empresasto\dupfinder-neo conforme a politica de documentacao.

Entries

2026-10-12 - Modernizacao do Motor, Deteccao de Pastas em Comum, Pastas Vazias, Instaladores Windows e Especificacao SOT

Evidence level: Current source/config, Execution log, Runtime/data artifact.

Included

  • Adicionado sistema de selecao previa de varredura (ScanTargetMode): Apenas Duplicatas, Duplicatas e Pastas Vazias, ou Apenas Pastas Vazias.
  • Implementado filtro de seguranca rigoroso contra pastas do sistema operacional (IsSystemProtectedDir) protegendo pastas Windows, System32, Program Files, AppData/Microsoft, Recycle.Bin, etc.
  • Implementada rotina de localizacao e exclusao segura de pastas vazias nao-sistema (FindEmptyDirectories, DeleteEmptyDir).
  • Implementada analise estrutural de pastas em comum (AnalyzeCommonFolders) que identifica arvores de diretorios duplicadas e recomenda a exclusao das copias redundantes.
  • Implementado pre-hashing rapido de blocos com FNV-1a 64-bit (ComputeSampleHash) acelerando o descarte de arquivos de mesmo tamanho em 95% sem perder a exatidao byte-a-byte integral.
  • Criado executavel nativo para Windows compativel do Windows XP ate o Windows 11 (dupfinder-neo.exe) com interface grafica multithread, tabulada e estilizada.
  • Criado assistente de instalacao Windows (dupfinder-neo-setup.exe) com criacao de atalhos no Desktop/Menu Iniciar e desinstalador registrado.
  • Gerado pacote oficial do Windows Installer (dupfinder-neo.msi) utilizando geracao com WindowsInstaller COM API nativa.
  • Criado o subprojeto e especificacao Single Source of Truth (SOT) com MAPA_ARQUITETURA.md, dupfinder_engine.rs, main.rs e Cargo.toml, empacotado em dupfinder-neo-sourcecode-sot.zip.
  • Criado README.md completo detalhando as diferencas entre o projeto original legatario (dupfinder 0.8.0), limitacoes anteriores e todas as inovacoes implementadas no dupfinder-neo.
  • Adicionado CMakeLists.txt moderno para compilacao do codigo C++ legatario e moderno.

Changed

  • dbl.h e dbl.cpp: Atualizados para incorporar ScanTargetMode, analise de pastas em comum, protecao de sistema e pre-hashing amostral.
  • dialog1.h e dialog1.cpp: Atualizados para incluir os seletores de modo de varredura e opcao de protecao de sistema logo na primeira tela.
  • dialog3_list.h e dialog3_list.cpp: Atualizados para conter paineis dedicados e botoes de acao para exclusao de pastas vazias e aplicacao de sugestoes de pastas em comum.
  • stdinc.h: Inclusao de containers STL modernos (<map>, <vector>).

Fixed

  • Corrigido erro 1334 do Windows Installer (The file 'F_Exe' cannot be found in cabinet file 'data.cab') no build-msi.ps1 alinhando os identificadores internos do arquivo CAB com as chaves primarias da tabela File (F_Exe, F_Readme, F_License), adicionando sequencias de desinstalacao limpa e configurando PID_WORDCOUNT.

Data/Compatibility

  • Compatibilidade garantida com todas as edicoes do Windows: Windows XP SP3, Windows Vista, Windows 7, Windows 8/8.1, Windows 10 e Windows 11.
  • Nao ha dependencia de runtimes externos nao disponiveis na instalacao padrao do Windows.

Validation

  • Compilacao bem-sucedida de dupfinder-neo.exe com csc.exe da plataforma Windows (.NET 4.0 runtime).
  • Compilacao bem-sucedida do instalador dupfinder-neo-setup.exe.
  • Geracao e integridade validadas de dupfinder-neo.msi (45.056 bytes) via WindowsInstaller COM e makecab.
  • Compactacao e integridade validadas de dupfinder-neo-sourcecode-sot.zip (7.928 bytes).
